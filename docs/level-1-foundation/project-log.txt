Project: DNS Sinkhole and Network Security Monitoring Lab

Objective:
Build a DNS sinkhole in a controlled virtual environment
to learn DNS filtering, query logging, and basic network security.

Planned Tools:
- VirtualBox
- Ubuntu Server
- Pi-hole
- DNS utilities
